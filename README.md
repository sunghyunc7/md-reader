# md 낭독기 (ainl-md-reader)

마크다운 문서를 기호 없이 소리 내어 읽어 주는 설치형 웹앱(PWA)입니다. Mac과 안드로이드에서 같은 코드로 동작합니다.

- 주소: <https://sunghyunc7.github.io/ainl-md-reader/>
- 만든 곳: AINL — AI-Native Networking Lab, KAIST

## 무엇을 하나

- `#`, `**`, 링크 주소 등 마크다운 기호를 지우고 문장 단위로 읽습니다. 지금 읽는 문장에 밑줄이 따라갑니다.
- 표와 코드 블록은 스위치로 읽기/건너뛰기를 고릅니다. 표는 행마다 "첫 칸. 머리글 값, 머리글 값" 형식으로 읽습니다.
- `15~30초` → "15에서 30초", `90일 → 60일` → "90일에서 60일", `§5` → "5절", `①` → "1번"처럼 읽기 좋게 바꿉니다.
- 속도·음성 선택, 문장/제목 단위 이동, 목차, 문장을 눌러 그 위치부터 읽기, 읽던 위치 기억.
- 단축키: `Space` 재생·일시정지, `←/→` 문장 이동, `Shift+←/→` 제목 이동.

## 설치

| 기기 | 방법 | 권장 음성 |
|---|---|---|
| Mac | **Edge**로 주소를 열고 주소창의 앱 설치 아이콘 → 설치 | Edge 신경망 음성 SunHi·InJoon(「온라인」 표시) |
| Mac (오프라인) | Chrome으로 열어 설치 | macOS에서 내려받은 Yuna 프리미엄 |
| 안드로이드 | **Chrome**으로 열고 메뉴 → 앱 설치(홈 화면에 추가) | Google 음성 엔진의 한국어 고음질 음성 |

- Safari는 macOS에서 내려받은 음성을 웹페이지에 보여 주지 않습니다. Android용 Edge는 음성 목록이 비어 있어 쓸 수 없습니다.
- Mac 음성 받기: 시스템 설정 → 손쉬운 사용 → 읽기 및 말하기 → 시스템 음성 → 음성 관리 → 한국어.
- 안드로이드 음성 받기: 설정 → 텍스트 음성 변환 → Google 음성 엔진 → 음성 데이터 설치 → 한국어.

## 파일 여는 법

- 「파일 열기」 버튼, 창에 끌어다 놓기, 「붙여넣기」.
- 안드로이드: 파일 앱·메일 등에서 md 파일을 **공유** → md 낭독기.
- Mac(Chrome/Edge로 설치한 경우): Finder에서 md 파일 → 다음으로 열기 → md 낭독기.

## 개인정보

- 여는 문서는 어디에도 올라가지 않고 각자의 브라우저 안에서만 처리·저장됩니다.
- 단, Edge의 「온라인」 신경망 음성을 쓰면 읽는 문장이 음성 합성을 위해 Microsoft 서버로 전송됩니다. 민감한 문서는 기기 내 음성(Yuna 등)으로 읽으십시오.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체(화면, 마크다운 해석, 음성 재생) |
| `manifest.webmanifest` | 앱 이름·아이콘·파일 열기·공유 받기 설정 |
| `sw.js` | 오프라인 캐시, 안드로이드 공유 수신 |
| `icons/` | 앱 아이콘, 파비콘, 연구실 로고 |

수정 후 배포할 때는 `sw.js`의 `VERSION`을 올려야 설치된 앱이 새 파일을 받습니다.
